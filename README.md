# Вайбидеи

Однофайловое приложение для поиска идей для вайб-кодинга. Готово для GitHub Pages: открой `index.html` в корне репозитория или загрузи его туда. Внешние JS/CSS-файлы, backend, AI-ключи и сборка не нужны.

## Возможности MVP

- Подбор 30+ идей с уровнями «Лёгкая», «Средняя» и «Сложная».
- Фильтры по опыту, цели, времени, платформе и темам; поле собственной темы.
- Карточки с проблемой, аудиторией, MVP, этапами, критериями готовности и рисками.
- Сохранённая библиотека, статусы «Сохранена / В работе / Готово», заметки и локальная история.
- Готовый промт для coding agent, копирование и экспорт подробного брифа в Markdown.
- Ремиксы, пропуск идеи, поиск/сортировка сохранённых и экспорт библиотеки в JSON.

## Запуск

Открой `index.html` или опубликуй его в корне репозитория GitHub Pages. Данные хранятся только в `localStorage` браузера и не синхронизируются между устройствами.

Подбор сейчас использует встроенную локальную библиотеку и фильтры — внешняя AI-модель не вызывается. Это честный автономный fallback без API-ключей.
